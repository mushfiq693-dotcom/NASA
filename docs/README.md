## 📋 Document Summaries

### 1. 🔍 Technical Audits & Verification (`docs/audit/`)
* **[BengalFlare_Technical_Audit_Report.md](audit/BengalFlare_Technical_Audit_Report.md):**  
  An evidence-based, skeptical technical audit detailing what the application actually implements versus early claims. Features bilingual explanations, real telemetry correlation figures ($r = 0.035$ at 1 km coincident overpass), and pipeline analysis.
* **[BengalFlare_Flaws_and_Production_Roadmap.md](audit/BengalFlare_Flaws_and_Production_Roadmap.md):**  
  A 10-point flaw inventory and production upgrade guide focused exclusively on refining existing features to production and NASA-winning standards without introducing scope creep.

### 2. 🔬 Scientific Research (`docs/research/`)
* **[MODIS_VIIRS_Harmonization_Research_Report_v2.md](research/MODIS_VIIRS_Harmonization_Research_Report_v2.md):**  
  The core academic research paper detailing sensor physical characteristics, bowtie distortions, diurnal overpasses, Fire Radiative Power (FRP) scaling, and cross-sensor harmonization theory.

### 3. 📐 System Architecture & Specifications (`docs/specifications/`)
* **[master_prompt_firechronicle_v3.md](specifications/master_prompt_firechronicle_v3.md):**  
  The complete master architectural blueprint defining the backend ETL pipeline, H3 geospatial indexing, API contracts, frontend layout constraints, and accessibility requirements.

### 4. 🎬 Media & Presentation Assets (`docs/media/`)
* **[BENGALFLARE_3M50S_FINAL_VIDEO_BLUEPRINT.md](media/BENGALFLARE_3M50S_FINAL_VIDEO_BLUEPRINT.md):**  
  Complete 3 minute 50 second official video blueprint, storyboard, AI video generation prompts, and editing blueprint.
* **[bengalflare_space_apps_3min10sec_video_script.md](media/bengalflare_space_apps_3min10sec_video_script.md):**  
  The word-for-word timed video narration script with scene-by-scene visual cues and live demonstration prompts.
